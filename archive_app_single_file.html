Adoption Template

The shared catalog every Plan draws from — every module and parameter that exists in the product, its weighting, and its Adoption/Expansion category. Which of these a given lab actually gets by default is decided per-Plan on the Plans screen, not here.

TEMPLATE ENGINE — SPEC'D Mirrors the separate Adoption Template Engine PRD (weighted modules & parameters, mandatory vs. optional, category). Adding/removing a parameter here changes what exists for every Plan to include or exclude — it doesn't rewrite adoption statuses already recorded per lab.

Plans

The named bundles Sales actually sells. Each lab is assigned one Plan, which sets its default module scope — the per-lab "In scope" tick on a lab's own Adoption tab can still give that one lab a custom offer without touching the Plan itself.

MASTER ENTITY Toggling a module here changes what this Plan includes going forward for labs on it — it never renames the Plan and never rewrites scope already recorded for a specific lab. A lab's own deviations from its Plan are tracked as notes on that lab, not as edits here.

CSM Setup

Your team roster — who's a CSM Lead vs. a CSM. Add teammates here so they show up as CSM options everywhere else (Add Lab, Reassign CSM, Tasks).

Lab History

Every logged check-in and system event, across all labs, newest first. Click a lab name to open its own Lab History tab for the full per-lab trail.
